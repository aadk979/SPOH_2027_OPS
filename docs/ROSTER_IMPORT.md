# Roster Import — CSV Spec (DRAFT v0.2)

One row per person. First row = headers exactly as below. Save as CSV (UTF-8) from Excel / Google Sheets.
Example rows use **fictional people**.

| Column                                           | Required               | Allowed values                             | Notes                                                                                                                                                                                                                                                                      |
| ------------------------------------------------ | ---------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                                           | Yes                    | Free text                                  | Display name                                                                                                                                                                                                                                                               |
| `email`                                          | Yes                    | SP iChat email                             | Unique key — used for login and to update a person on re-import                                                                                                                                                                                                            |
| `phone`                                          | No                     | 8-digit SG number                          | For coordinators to call; leave blank if not wanted                                                                                                                                                                                                                        |
| `course`                                         | No                     | DAAA, DCDF, DCS, DCITP, Other              | Useful for course-matched posts (e.g., DCDF ushers at Wargame Centre)                                                                                                                                                                                                      |
| `rank`                                           | Yes                    | CC, Deputy, IC, Shadow IC, Volunteer       | Drives permissions                                                                                                                                                                                                                                                         |
| `team`                                           | Yes for IC & Volunteer | One of the team list (below)               | For a Deputy: their portfolio name. Blank for CC / Shadow IC                                                                                                                                                                                                               |
| `shadows`                                        | Shadow IC only         | Name of the portfolio they shadow, or `CC` |                                                                                                                                                                                                                                                                            |
| `day_YYYY-MM-DD` (one column per configured day) | Yes                    | Y / N                                      | Availability per event day. **Columns follow the days configured in the app.** Download the current template from the Import screen, so adding or removing a day changes the template automatically. Unknown day columns are rejected; missing day columns = not available |

**Team list (confirmed 2026-11-18):** Welcome Party, Sign-Up Booth, Welcome Lounge, Guides, Room Ushers, Relief, Visitor Tracking, Student Facilitators DAAA, Student Facilitators DCDF, Student Facilitators DCS, Course Counselling, Gift Redemption, Welfare, Safety, Communications.

**Deputy portfolios:** Visitor Experience & Engagement; Course Experience & Station Support; Operations & Crowd Management; Course Counselling & Gift Redemption; Welfare, Safety & Communications.

**Import behaviour (planned):** validate the whole file first and show row-by-row errors; nothing is saved until the file is clean. Re-importing updates people by `email` (no duplicates).
